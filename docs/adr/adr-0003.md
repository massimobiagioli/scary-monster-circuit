# ADR-0003: Audio playback through a UART MP3 player

- **Status:** Accepted
- **Date:** 2026-09-27

## Context

The prop must play a scary song when someone gets close. The RP2040 has no
built-in audio output and generating audio in firmware is complex and
distracting from the core behavior.

## Decision

- Use a **DFPlayer-style MP3 module** driven over **UART**.
- The song is stored as the first track on the module's SD card.
- The firmware sends a single "play track 1" command when it enters the
  `Action` state.

## Consequences

- Audio is offloaded to a dedicated module; the firmware stays simple.
- Only the command frame is implemented, keeping the driver small and testable.
- Swapping the sound only requires replacing the file on the SD card.
