# ADR-0019: The servo moves only when the behavior state changes


- **Status:** Accepted
- **Date:** 2026-10-11

## Context

Even after the servo stopped rewriting the same duty cycle (ADR-0018), the head
still moved constantly: in `Follow` the direction is picked from the two
sensors, and with noisy readings it flipped left/centre/right several times a
second, so the head kept turning. The log gave no hint of when the servo had
actually been commanded.

## Decision

- `Controller` positions the head **once per behavior state**. It remembers the
  state it was last positioned for (`commanded`); when the state does not
  change, the head is not touched at all. A state change sets the head to the
  side of the nearest sensor in `Follow`, or to the centre otherwise.
- `StateMachine` uses hysteresis for `Follow`: it starts when the nearest sensor
  is within `FOLLOW_DISTANCE_CM` and ends only past `FOLLOW_EXIT_CM`. A reading
  hovering around the threshold cannot flicker the state, which used to make the
  head jump to the centre and back (`45 -> 90 -> 45`).
- `Head` still ignores a repeated angle (ADR-0018) and exposes `take_changed()`;
  `Snapshot` carries a `servo_moved` flag, so the row flags a real move with a
  trailing `*`: `90 deg *`.

## Consequences

- A steady state produces no new servo pulses at all; the head only turns when
  the prop changes mood. The "drill" effect is gone.
- The state no longer flickers around 60 cm, so `Follow` is not reported while
  nobody is within reach and the head does not jump to the centre and back.
- The head is set from a single reading when `Follow` starts; it does not keep
  chasing within the same state. That is the trade-off for a perfectly still
  head, and it can be revisited if finer tracking is wanted.
- The log makes it obvious when the servo was commanded, which helps diagnose
  wiring and calibration.
- Note: a positional servo must keep receiving its pulse train to hold a
  position; "no pulse" would leave it limp. This decision is about not *changing*
  the pulse, not about stopping it.
