# ADR-0005: Markdown-to-PDF tool with Mermaid and a Python venv

- **Status:** Accepted
- **Date:** 2026-09-27

## Context

The project needs a single PDF with all schematics. The diagrams are written in
Mermaid so they stay easy to edit and review as text. We must not install system
packages with Homebrew, and Python tools must run inside a virtual environment.

## Decision

- Add a reusable tool at `tools/md2pdf/` that converts a Markdown file with
  Mermaid diagrams into a PDF.
- The tool is written in Python and runs inside its own `.venv`, created on
  first use. Dependencies are pinned in `requirements.txt`.
- Mermaid blocks are rendered to PNG images through the public `mermaid.ink`
  service, with retries and PNG validation to survive slow responses; the
  Markdown is converted to HTML and then to PDF.
- Schematics live in `schematics/`; `make schematics` rebuilds every
  `schematics/*.md` file into a matching PDF.
- Alongside the reference schematics, `schematics/step-by-step-instructions.md`
  provides LEGO-style assembly instructions with breadboard views.

## Consequences

- One tool and one command produce every schematic PDF.
- No system-level package installation is required.
- Rendering Mermaid needs network access to `mermaid.ink`.
