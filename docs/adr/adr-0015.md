# ADR-0015: Live log with a one-time header and one-line rows

- **Status:** Accepted
- **Date:** 2026-10-11

## Context

The live dashboard reprinted a full box, title included, on every snapshot
(once per second). The repeated `SCARY MONSTER PROBE` header and the box borders
made the log noisy, and because event lines (`person close: playing track 1`)
were interleaved between box lines, the servo and mp3 values were hard to read.
A developer watching `make logs` wants to see every component clearly.

## Decision

- Print the title and column labels once, when a host opens the serial port.
- Then print one aligned row per second with the current value of every
  component: `state`, `left` sensor, `right` sensor, `servo` angle and `mp3`
  track, followed by a short `!` note naming any component that looks broken.
- Implement this as `render_header` + [`Snapshot::render_row`] in
  `firmware/src/lib/probe.rs`; remove the boxed `render`.
- The `Logger` is now a plain transport: it no longer prints a hardcoded banner,
  and the header is re-sent each time a host (re)opens the port.

## Consequences

- `make logs` shows a readable, compact stream of live values; the header does
  not scroll away under repeated copies.
- Problems are visible inline (`! left sensor servo`) instead of in a separate
  box section.
- The header and rows share fixed column widths, pinned by tests.
