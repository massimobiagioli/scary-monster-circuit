# ADR-0010: Flash over USB without a debug probe

- **Status:** Accepted
- **Date:** 2026-10-11

## Context

`make upload-firmware` ran the firmware through the Cargo runner, `probe-rs`.
That tool talks to the chip over SWD and needs a hardware debug probe (for
example a Raspberry Pi Debug Probe or a second Pico running `debugprobe`). A
Pico connected only with a USB cable, already running firmware, does not show up
as a probe, so `make upload-firmware` failed with "No connected probes were
found" on the basic single-cable setup. This blocked the first flash and broke
the buildability principle.

The RP2040 has a ROM USB bootloader: hold BOOTSEL while plugging USB and the chip
appears as a mass-storage volume that accepts a `.uf2` file. An ELF can be
converted to UF2 and copied to that volume, so flashing needs only the USB
cable.

## Decision

- Flash over USB: `make upload-firmware` builds the release ELF and deploys it
  with `elf2uf2-rs -d`, which finds the mounted BOOTSEL volume and copies the
  UF2 onto it.
- Provide `elf2uf2-rs` project-local and pinned, like `probe-rs`: a wrapper
  `tools/elf2uf2-rs/elf2uf2-rs` installs the pinned version (see
  `tools/elf2uf2-rs/version.txt`) on first use. No global `cargo install`.
- Keep `probe-rs` for debug-probe flashing. (Logs were later moved off RTT onto
  USB serial in [ADR-0011](adr-0011.md), so `make logs` no longer needs a probe.)
- Tell the user to put the Pico in BOOTSEL mode before flashing, and document
  that `make logs`/`make probe` need a real debug probe.

## Consequences

- Flashing works with nothing but a USB cable; no debug probe is required for
  the basic edit/build/flash loop.
- The Pico must be put into BOOTSEL mode by hand (hold the button while plugging
  USB); the tool then finds the mounted volume.
- A running Pico does not expose RTT over USB; logging was later moved to USB
  serial in [ADR-0011](adr-0011.md).
- A fresh checkout installs and compiles the pinned `elf2uf2-rs` on the first
  `make upload-firmware` (slow once, fast afterwards).
